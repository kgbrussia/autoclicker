# KGB Автокликер — GitHub Pages

Базовый URL: `https://kgbrussia.github.io/autoclicker`

1. Репозиторий **autoclicker** на GitHub (public).
2. Залить содержимое этой папки `docs/` в корень репо или оставить в `/docs`.
3. Settings → Pages → branch `main` → folder `/docs`.
4. Проверка: `https://kgbrussia.github.io/autoclicker/privacy.html`

Перегенерация: `python3 scripts/texts/gen_legal.py`
